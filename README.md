# Lettersvg — Red Envelope

A responsive, code-drawn recreation of a red envelope using SVG.

## Preview
Open `index.html` in a browser or visit the live deployment.

## Source files
- `index.html` — responsive page for the envelope.
- `red-letter.svg` — editable vector artwork made with SVG paths, gradients, folds, texture filters, and shadows.

The illustration has a transparent background and no external dependencies.
